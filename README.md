TP3 - Développement Mobile

📌 Description

Ce projet a pour objectif de pratiquer le développement d'applications mobiles Android en utilisant Java et XML.

🎯 Objectifs

- Créer une interface graphique avec XML.
- Utiliser les composants Android.
- Gérer les événements des boutons.
- Effectuer des calculs et des conversions.
- Comprendre les classes et l'héritage en Java.

🛠️ Technologies utilisées

- Java
- XML
- Android Studio

📚 Contenu du TP

Exercice 1 : Périmètre d'un cercle

Calculer le périmètre d'un cercle à partir de son rayon.

Exercice 2 : Convertisseur de devises

Convertir un montant en dirhams marocains (MAD) vers une autre devise.

Exercice 3 : Classes Personne et Étudiant

Manipuler les classes Java, les attributs et l'héritage.

🚀 Installation

1. Télécharger ou cloner le projet.
2. Ouvrir le projet avec Android Studio.
3. Attendre la synchronisation de Gradle.
4. Exécuter l'application sur un émulateur ou un appareil Android.
